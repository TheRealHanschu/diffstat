# Changelog

## 0.3.0

- The Line Changes view can group files by folder, with totals for each folder. Switch between list and tree with the button in the view's title bar.
- Sort files by path, by lines changed or by lines added, from **Sort By...** in the view's `...` menu.
- Right-click a file to open it, stage, unstage or discard its changes, copy its path or reveal it in the Explorer.
- Faster updates: line counts of untracked files are reused until the file changes, and git runs its diffs in parallel.

## 0.2.0

- The status bar shows the lines added and removed in the file you're editing. 

## 0.1.0

- First release: the Line Changes view with colored counts and added/removed bars in the Source Control tab, a colored status bar total, an option to split staged and unstaged changes, and line counts for untracked files.
